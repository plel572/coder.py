# coder.py
Код, который написан через Нейросеть Cloude зашифрует или просто превратит любой файл (от .exe до .mp4) в видео с разноцветными пикселями. С помощью видео можно будет сделать обратный путь до того файла, который Вы дали этому коду. Видео можно загрузить на YouTube, чтобы это видео не занимало место на ПК.
